Transform a Network model into a Graph model while preserving system containment and link connectivity.

Each Component is transformed into an Entity.

The name of the Component is copied to the name of the Entity.

Each System is transformed into a Root.

The components of the System are copied to the entities of the Root.

Each Link is transformed into a Link.

The components of the Link are copied to the Entitys of the Link.

Create exactly one reusable Entity for each Component so that every reference to the same source Component resolves to the same target object. Each Root must contain the entities corresponding to its System's components. Each target Link must connect the entities corresponding to its source Link's components.
