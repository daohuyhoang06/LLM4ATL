Create one ATL transformation module named `UML2Java_All` for all supplied UML input models. Use the header `create OUT : Java from IN : UML;`, where UML is the supplied UML.ecore and Java is the supplied java.ecore. Do not specialize the transformation to an individual example.

Map a UML Model or Package to a Java Package, and UML Classes to Java Classes. Copy names where present; handle missing names safely. Map UML ownedAttribute Properties to Java Fields, preserving name, visibility, multiplicity/list information and a readable typeName (primitive or named classifier). Map UML ownedOperation and ownedParameter to Java Methods and Params where the target metamodel permits. Preserve abstract/interface flags and superclass names when available. Avoid creating invalid target references or dereferencing undefined values.

The target java.ecore is deliberately small: Package, Class, Field, Method and Param. It has no Enumeration or EnumerationLiteral. Do not invent target EClasses or features; enum coverage cannot be evaluated with this target metamodel. The ten UML XMI fixtures and Java oracle files are evaluation data, not a transformation reference and not examples to hard-code.
