Transform a DSL DomainModel into a KM3 metamodel. Create the KM3 metamodel root with a package for the domain concepts and a PrimitiveTypes package for the primitive datatypes.

Each DomainModel is transformed into a Metamodel.

Each Class is transformed into a Class.

Each Relationship is transformed into a Class.

Each Role is transformed into a Reference.

Each ValueProperty is transformed into an Attribute.

Each Enumeration is transformed into an Enumeration.

Each EnumerationLiteral is transformed into an EnumLiteral.

Each SimpleType is transformed into a DataType.

A Relationship must be represented as a KM3 Class when it has incoming roles, super-types, sub-types, or properties. Otherwise, its roles must be represented as references owned by the corresponding classes. Infer whether each reference is a containment reference from the source role and relationship structure.

Preserve names, inheritance, types, multiplicities, ownership, opposite references, and containment. Put domain classifiers in the main package and primitive datatypes in PrimitiveTypes. References created from the two ends of a relationship must remain mutually consistent.
