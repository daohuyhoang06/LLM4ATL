Transform an IEEE 1471 architectural description into a MoDAF architecture view. Preserve the architectural organization and traceable relationships between systems, environments, missions, architectures, descriptions, stakeholders, viewpoints, views, models, and concerns.

Each IEEE1471Model is transformed into a MoDAFModel.

Each System is transformed into an Enterprise.

Each Environment is transformed into an Environment.

Each Mission is transformed into an OperationalMission.

Each Architecture is transformed into an Architecture.

Each ArchitecturalDescription is transformed into an ArchitecturalDescription.

Each Stakeholder is transformed into a Stakeholder.

Each Viewpoint is transformed into a View.

Each View is transformed into an ArchitecturalProduct.

Each Model is transformed into an Element.

Each Concern is transformed into a Concern.

Each LibraryViewpoint is transformed into an ArchitecturalFramework.

Build a rationale value by combining the name and content of the first available Rationale. The target model must also contain a default ArchitecturalFramework that owns every Viewpoint that has no source framework. For every consistent Stakeholder and Concern pair in the source, create a StakeholderHasConcern relationship owned by the generated MoDAFModel and connect it to their generated target elements.
