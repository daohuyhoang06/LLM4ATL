Transform a Petri net into an equivalent Grafcet while preserving its names, locations, containment, and connectivity.

Each PetriNet is transformed into a Grafcet.

Each Place is transformed into a Step.

Each Transition is transformed into a Transition.

Each PlaceToTransition is transformed into a StepToTransition.

Each TransitionToPlace is transformed into a TransitionToStep.

The location of the PetriNet is copied to the location of the Grafcet.

The name of the PetriNet is copied to the name of the Grafcet.

The location and name of every Place, Transition, and arc must be preserved in its corresponding target element. All generated steps, transitions, and connections must belong to the generated Grafcet. Preserve the source and target ends of every arc, and rebuild the incoming and outgoing connection references so that the target Grafcet has the same topology as the source Petri net. Initialize isInitial and isActive to false for every generated Step.
