Transform a model conforming to the Amalthea metamodel into a model conforming to the Ascet metamodel. Name the ATL transformation AmaltheaToAscet_All.

Each ComponentContainer is transformed into an AscetModule.

The tasks of the ComponentContainer are copied to the tasks of the AscetModule.

Each Task is transformed into a SoftwareTask.

The name of the Task is copied to the name of the SoftwareTask.

For every ComponentContainer, populate its resulting AscetModule with the SoftwareTask produced from every contained Task. A Task that has no container must also produce a SoftwareTask. Reuse the same Task-to-SoftwareTask mapping consistently whenever a Task is referenced.
