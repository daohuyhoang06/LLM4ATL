Create one ATL transformation module named `SysMLv2ToAAS_All` for all supplied SysML v2 input models. Use the header `create OUT : AAS from IN : sysml;`, where sysml is the exact EPackage name declared by the supplied SysMLv2.ecore and AAS is the supplied AAS.ecore. Do not specialize it to an individual example.

Traverse the source metamodel's real containment path, especially Element.ownedRelationship and Relationship.ownedRelatedElement; many convenience references such as ownedMember, ownedFeature and name are derived/transient, not serialized input. Use declaredName for names. Map PartDefinition, PartUsage, PortDefinition, PortUsage, InterfaceDefinition, InterfaceUsage, OccurrenceDefinition, OccurrenceUsage, EventOccurrenceUsage, FlowConnectionUsage, SuccessionAsUsage, ItemDefinition and ItemUsage to nested AAS Entity elements with corresponding Qualifier.type. Map AttributeDefinition and AttributeUsage to AAS Property with corresponding qualifier. Preserve the hierarchy and names. Where the AAS metamodel permits, represent typed usages and connections as relationships. Guard optional names and references.

The ten textual `.sysml` sources are retained for provenance. Evaluation uses their separately prepared `.xmi` model fixtures and `.aas` oracle outputs. They are test data, not reference ATL; do not hard-code their names or expected structures.
