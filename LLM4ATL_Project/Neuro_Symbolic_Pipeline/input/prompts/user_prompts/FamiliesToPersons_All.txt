Transform a model conforming to the Families metamodel into a model conforming to the Persons metamodel. Name the ATL transformation FamiliesToPersons_All.

Each FamilyRegister is transformed into a PersonRegister.

The id of the FamilyRegister is copied to the id of the PersonRegister.

Each Member is transformed into a Male.

Each Member is transformed into a Female.

A Member represents a male person when the Member is a father or a son. A Member represents a female person when the Member is a mother or a daughter. Use these conditions to ensure that each Member is transformed into the correct target class.

Determine a Member's family last name from the associated Family. Prefer the family connected through the father role, followed by the mother role, the son role, and finally the daughter role. Set the fullName of the resulting Male or Female to the Member's firstName, followed by a space and the determined family last name.
