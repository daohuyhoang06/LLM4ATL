Transform a model conforming to the ER metamodel into a relational database model conforming to the REL metamodel. Use only ATL matched rules; do not use lazy rules or called rules.

Each ERSchema is transformed into a RELSchema.

Each Entity is transformed into a Relation.

Each Relship is transformed into a Relation.

Each ERAttribute is transformed into a RELAttribute.

The name of the Entity is copied to the name of the Relation.

The name of the Relship is copied to the name of the Relation.

The name of the ERAttribute is copied to the name of the RELAttribute.

The isKey of the ERAttribute is copied to the isKey of the RELAttribute.

The RELSchema must contain the Relation produced from every Entity and every Relship in its source ERSchema. A RELAttribute produced from an ERAttribute must belong to the Relation produced from the attribute's owning Entity or Relship.

For every RelshipEnd of a Relship, identify the participating Entity and copy each of that Entity's primary-key ERAttribute objects into the Relation produced from the Relship. These additional RELAttribute objects represent foreign keys and preserve the source attribute names and key information.
