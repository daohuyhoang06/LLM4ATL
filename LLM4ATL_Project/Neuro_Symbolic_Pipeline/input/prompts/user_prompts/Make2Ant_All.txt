Transform a Make build description into an equivalent Ant project. Preserve the project name, variables, targets, dependencies, commands, and whether command text is displayed.

Each Makefile is transformed into a Project.

The name of the Makefile is copied to the name of the Project.

Each Macro is transformed into a PropertyValue.

Each Rule is transformed into a Target.

The name of the Rule is copied to the name of the Target.

Each ShellLine is transformed into an Exec.

The Project must contain the properties produced from all Macros and the targets produced from all Rules. Use the first Rule as the default target when one exists. Copy each Macro's name and value to its PropertyValue, and preserve Rule dependencies as references between the corresponding targets.

Every ShellLine must produce an Exec task initialized from its command and associated with the target produced from its owning Rule. When display is true, it must additionally produce an Echo task for the same command. When display is false, it must produce only the Exec task.
