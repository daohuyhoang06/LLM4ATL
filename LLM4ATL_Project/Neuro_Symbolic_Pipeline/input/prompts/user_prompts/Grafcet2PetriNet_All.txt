Transform a Grafcet model into an equivalent Petri net while preserving its names, locations, containment, and connectivity.

Each Grafcet is transformed into a PetriNet.

Each Step is transformed into a Place.

Each Transition is transformed into a Transition.

Each StepToTransition is transformed into a PlaceToTransition.

Each TransitionToStep is transformed into a TransitionToPlace.

The location of the Grafcet is copied to the location of the PetriNet.

The name of the Grafcet is copied to the name of the PetriNet.

The location and name of every Step, Transition, and connection must be preserved in its corresponding target element. All generated places, transitions, and arcs must belong to the generated PetriNet. Preserve the source and target ends of every connection, and rebuild the incoming and outgoing arc references so that the target graph has the same topology as the source Grafcet.
