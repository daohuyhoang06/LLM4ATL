Transform a model conforming to the Class metamodel into a model conforming to the Interface metamodel. Name the ATL transformation Class2Interface_All.

Each ClassModel is transformed into an InterfaceModel.

The classes of the ClassModel are copied to the interfaces of the InterfaceModel.

Each Class is transformed into an Interface.

The name of the Class is copied to the name of the Interface.

The methods of the Class are copied to the methods of the Interface.

Each Method is transformed into a Method.

The name of the Method is copied to the name of the Method.

The returnType of the Method is copied to the returnType of the Method.

The parameters of the Method are copied to the parameters of the Method.

Each Parameter is transformed into a Parameter.

The name of the Parameter is copied to the name of the Parameter.

The type of the Parameter is copied to the type of the Parameter.
