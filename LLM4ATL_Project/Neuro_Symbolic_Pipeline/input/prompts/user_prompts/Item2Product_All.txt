Transform a model conforming to the Item metamodel into a model conforming to the Product metamodel. Name the ATL transformation Item2Product_All.

Each ItemModel is transformed into a ProductModel.

The items of the ItemModel are copied to the products of the ProductModel.

Each Item is transformed into a Product.

The name of the Item is copied to the name of the Product.

The price of the Item is copied to the price of the Product.

The description of the Item is copied to the description of the Product.

Set the inStock value of the Product to true when the quantity of the Item is greater than zero. Otherwise, set inStock to false.

Set the category of the Product to "Tech" when the type of the Item is "Electronics". Set it to "Apparel" when the type is "Clothing". Use "General" for every other type.
